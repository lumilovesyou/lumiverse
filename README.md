# Lumiverse

My Personal website for the world wide web

## Running locally

1. Clone project - `git clone https://github.com/lumilovesyou/lumiverse.git`

2. Open directory - `cd lumiverse`

3. Set up environment - `python3 -m venv .venv && source .venv/bin/activate && pip3 install -r requirements.txt`

4. Start server - `python3 index.py`
